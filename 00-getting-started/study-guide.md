# 학습 방법과 12주 일정

[목차](../README.md)

한 장에서 먼저 개념을 읽고 자기 말로 설명한다. 확인 문제에 답한 뒤 실습을 수행하거나 설계 산출물을 만든다. 시험형 문제는 정답을 보기 전에 풀고, 각 오답이 왜 요구사항을 만족하지 않는지 설명한다. 다음 날 문서를 덮고 핵심 절차를 다시 말한다.

## 일정

| 주 | 챕터 | 주간 산출물 |
|---|---|---|
| 1 | 01~03 | 서버·DNS 요청 흐름과 dev/prod 계층 설계 |
| 2 | 04~06 | 계정·프로젝트·API·quota·예산 점검표 |
| 3 | 07~09 | VM 접속·복구·확장 원리 설명 |
| 4 | 10~12 | 객체/파일/DB/분석 제품 선택표 |
| 5 | 13~15 | VPC·NAT·LB·하이브리드 연결 설계 |
| 6 | 16~18 | 이미지 빌드·Cloud Run·이벤트 경로 |
| 7 | 19~20 | Kubernetes 선언과 Terraform plan 해석 |
| 8 | 21~23 | 오류 검색·경보·장애 대응 기록 |
| 9 | 24~26 | 최소 권한·WIF·비밀 전달 설계 |
| 10 | 27 | 통합 서비스 배포·운영·정리 증거 |
| 11 | 28 + 모의고사 1 | 영역별 오답 분석과 재학습 |
| 12 | 모의고사 2 + 복습 | 핵심 실습을 설명 또는 재현 |

권장 주간 배분은 개념 3시간, 실습 3~5시간, 문제·복습 2~4시간이다. 기초가 어렵거나 실습 비용을 제한해야 하면 읽기·설계부터 진행하고 Google Skills 임시 실습 환경도 검토한다. 유료 실습을 생략한 항목은 progress에 미실행으로 남긴다.

## 챕터 통과와 응시 준비

- 각 장 6문항을 모두 설명할 수 있게 오답을 복습한다. 첫 점수와 재풀이 점수를 구분한다.
- 핵심 실습: 프로젝트 설정, VM/IAP, 비공개 bucket, Cloud Run 인증, 로그 검색, IAM 범위, Terraform 계획, GKE 상태 진단.
- 모의고사 두 회를 각 120분에 풀어 각각 51/60(85%) 이상을 자체 목표로 삼는다. 공식 합격 점수가 아니다.
- 영어 문제 대비: 제품명·CLI는 영어 그대로 익히고 requirements, minimal operational overhead, least privilege를 문장 안에서 해석한다.
- 시험 예약 직전 공식 시험 안내와 PDF 변경 여부를 확인한다.
